# Pragun Sharma Portfolio

Static Vite + React portfolio for Pragun Sharma. The frontend does not call the FastAPI backend; the `backend/` folder is retained for reference but is not deployed. Contact uses EmailJS when the three `VITE_EMAILJS_*` variables are configured.

## Required `[FILL]` items

- Add the final resume at `public/Pragun_Sharma_Resume.pdf`.
- Replace each project `[FILL repo URL]` value in `src/data/profile.js` with its own repository URL.
- Add one optimized WebP photo under 60 KB only if a portrait is desired.

## Commands

```bash
npm ci
npm run build
```
